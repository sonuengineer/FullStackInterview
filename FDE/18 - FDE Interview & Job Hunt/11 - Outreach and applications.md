# FDE Interview & Job Hunt

## Outreach and applications

> Core | Fast CP8 / Slow CP10 | ~0.5 h | Builds on: M18-01, M18-02, M18-03

### Kahani
Ankit ne ek din mein 80 jobs pe "Easy Apply" kiya. Same resume, koi note nahi. 3 hafte baad: 2 auto-rejections, baaki silence.
Uski dost Sneha ne hafte mein sirf 10 applications bheje -- har ek ke liye resume ka top tailor kiya, aur 4 mein kisi engineer se referral maanga. 2 interviews mile.
Volume zaroori hai, par **targeted** volume. Is lesson mein ek weekly system banate hain jo spray-and-pray se bachata hai aur steady pipeline deta hai.

### What it is
Ek weekly routine: target list -> tailoring -> referral asks -> applications -> tracking -> follow-ups. Target: **10 quality applications per week** once you start applying (fast track CP5, slow track month 3).

### Why it matters for an FDE
FDE roles kam hain aur competitive. Referrals aur tailored applications response rate bahut badhate hain, aur outreach khud ek FDE skill hai -- stranger ko short, clear, respectful message likhna.

### Key concepts
- **Target list** -- 30-40 companies, 3 tiers: reach (AI labs), match (AI startups, GCCs), safe (adjacent roles). Weekly 10 isi list se.
- **Tailoring in 15 minutes** -- summary line + top 3 bullets ko post ki top 3 requirements se match karo (M18-01 table use karo).
- **Referral ask** -- short, specific, easy to say yes; ek proof link ke saath.
- **Follow-up cadence** -- 5-7 working days baad ek polite follow-up; uske baad move on.
- **Tracking** -- har application portal mein, status update ke saath. XP 10/week pe capped hai -- spam ka koi fayda nahi.

### How to do it
Weekly routine (~3-4 hours spread over the week):
| Day | Task |
|---|---|
| Mon | Pick 10 roles from target list; save post text (M18-01 habit) |
| Tue | Tailor resume summary + top bullets for each (15 min each) |
| Wed | Send 4-6 referral asks / warm messages |
| Thu | Submit applications; log each in portal |
| Fri | Follow-ups for 7-day-old items; update statuses; 1 LinkedIn post about what you built |

Target list template (keep it in your private notes):
```text
| Company | Tier (reach/match/safe) | Role titles they use | Careers page | Contact for referral | Last checked |
|---------|-------------------------|----------------------|--------------|----------------------|--------------|
|         |                         |                      |              |                      |              |
```
Har 2 hafte "Last checked" update karo -- band hui roles hatao, nayi companies add karo.

Tracking in the portal: **Job hunt -> Applications -> Add application** (company, role, job link, note e.g. "referral: <name>"). Status dropdown update karo: applied -> referred -> screening -> interview -> offer / rejected. Jab koi application "interview" tak pahunche, "First interview" tile set ho jaata hai.

#### Message templates (English, paste-ready)
Referral ask (engineer at the company, no prior contact):
```text
Hi <name>, I am a full-stack engineer moving into Forward Deployed / Applied AI work. I saw the <role> opening at <company> (<link>).
I recently built OmniGuard, a secure RAG + Text-to-SQL assistant with RBAC and PII guardrails (<faithfulness score> faithfulness, 4-min demo: <video link>).
If you think my background fits, would you be open to referring me? Happy to send a short summary to make it easy. No worries if not.
```
Warm ask (someone you know):
```text
Hi <name>, hope you are well. I am applying for <role> at <company>. You know my work from <shared context>; since then I have built two deployed AI projects (<github link>).
Would you be comfortable referring me, or pointing me to the right person on that team? Thank you either way.
```
Recruiter / hiring manager note:
```text
Hi <name>, I applied for <role> today. The role asks for <requirement 1> and <requirement 2>; my AuditMesh project does exactly that -- a multi-agent compliance workflow with human approval and a Jira MCP server, demo here: <link>.
I would value a short conversation if you think there is a fit.
```
Follow-up (7 working days later):
```text
Hi <name>, following up on my note about <role>. Since then I added <one new thing, e.g. an eval report>. Happy to share more if useful. Thanks for your time.
```

### Practice set
1. Build the 30-40 company target list with tier and careers-page link.
2. Do one full weekly cycle: 10 applications, 4+ referral asks, all logged in the portal.
3. Ask Claude to critique 2 of your outreach messages: "Make this shorter and more specific; keep it polite and honest."

### Rubric
| Check | Weekly target |
|---|---|
| Applications logged | 10 |
| Each tailored (summary + top bullets) | 10/10 |
| Referral / warm asks sent | 4+ |
| Follow-ups sent on 7-day-old items | all |
| Statuses current in portal | yes |

### Common pitfalls
- 80 Easy Applies, zero tailoring. Response rate gir jaata hai aur aap demotivate hote ho.
- Lamba referral message with full life story. 3-4 lines, ek link, easy yes.
- Rejection ko personal lena aur ek hafte rukna. Pipeline chalti rehni chahiye -- har week same routine.

### Checklist before moving on
- [ ] Target list ready (30-40 companies, tiered)
- [ ] Templates personalised with your real links
- [ ] One full week completed and logged in Job hunt -> Applications
- [ ] Friday follow-up habit set as a recurring reminder

### Self-quiz
1. Why does the portal cap application XP at 10 per week, and what behaviour does that encourage?
2. What three elements make a referral ask easy for a stranger to say yes to?
3. When should you stop following up on an application, and what do you do instead?
