# Project 1: OmniGuard — Secure AI Integration

Build a secure enterprise AI integration system designed for real-world corporate environments. You'll implement Hybrid RAG, secure Text-to-SQL, OAuth 2.0 and RBAC, SQL database integration, NeMo and Presidio guardrails, and a Dockerized FastAPI deployment on the cloud. You'll also experience the complete FDE consulting lifecycle—from technical discovery and data classification to architecture SOWs, ROI presentations, and UAT runbooks.

## Deliverables
1. Hybrid RAG implementation
2. Secure Text-to-SQL
3. OAuth 2.0 and RBAC
4. SQL database integration
5. NeMo guardrails
6. Presidio guardrails
7. Dockerized FastAPI deployment on cloud
8. Technical discovery and scoping
9. Data classification
10. Architecture SOW
11. ROI presentation for CISO and executives
12. UAT runbook

## Learn vs build -- how the two folders fit

- **`15 - OmniGuard - Secure AI Integration/`** = LEARN. Lessons that teach the skill (story, code, exercise, quiz).
- **`Projects/Project 1 - OmniGuard - Secure AI Integration/`** (this folder) = BUILD. Briefs for what you ship: goal, what to build, acceptance checks, gate proof.
- Order: read the lesson, then build the brief in your own `omniguard` repo. You write the code; Claude reviews.
